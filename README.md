# Yuzhen's Blog

一个使用 Astro 搭建的个人博客，用来整理文章、主题记录和个人作品。

## 本地开发

```bash
npm install
npm run dev
```

默认本地地址：

```text
http://127.0.0.1:4321/
```

## 常用命令

```bash
npm run check
npm run build
npm run preview
```

## 内容位置

- 文章：`src/content/articles/`
- 主题：`src/content/topics/`
- 作品：`src/content/works/`
- 站点信息：`src/config/site.ts`

原始日记导出、本地依赖和构建产物不会提交到 GitHub。
