## ADDED Requirements

### Requirement: 公开内容必须经过明确筛选
系统 SHALL 只发布位于公开内容源目录、并且具备对应内容类型所需元数据的内容。

#### Scenario: 仓库中存在原始日记导出
- **WHEN** 网站执行构建
- **THEN** 位于公开内容源目录之外的原始 flomo 或日记导出文件不会被生成为公开页面

### Requirement: 文章具备结构化元数据
公开文章 SHALL 包含结构化元数据：标题、发布日期、摘要、主题引用、发布状态，以及可选的原始来源链接。

#### Scenario: 文章出现在列表中
- **WHEN** 一篇文章被纳入公开文章集合
- **THEN** 文章列表可以从结构化字段中渲染标题、日期、摘要和主题信息

### Requirement: 作品具备结构化元数据
公开作品 SHALL 包含结构化元数据：标题、日期、摘要、作品类型、发布状态，以及可选链接或封面媒体。

#### Scenario: 作品出现在作品页
- **WHEN** 一个作品条目被纳入公开作品集合
- **THEN** 作品页可以从结构化字段中渲染标题、摘要、类型、日期和相关链接或媒体

### Requirement: 主题有人工策划的定义
主题 SHALL 被定义为人工策划的公开主题，包含名称、slug、摘要，以及可选排序或精选状态。

#### Scenario: 主题出现在首页
- **WHEN** 一个主题被标记为精选
- **THEN** 首页可以把它展示为长期阅读路径

### Requirement: 草稿内容不进入生产页面
系统 SHALL 在生产构建时排除草稿内容，使其不出现在公开列表和详情页中。

#### Scenario: 存在草稿文章
- **WHEN** 一篇文章被标记为草稿
- **THEN** 生产站点不会在列表中展示该文章，也不会暴露它的公开详情页

### Requirement: 来源于公众号的内容保留来源信息
从微信公众号文章改写或迁移来的文章 SHALL 支持可选来源标注，方便读者在作者提供链接时识别原始发布路径。

#### Scenario: 存在公众号来源链接
- **WHEN** 一篇公开文章包含原始公众号 URL
- **THEN** 文章详情页可以展示原文链接或来源说明

### Requirement: 媒体资源只使用明确公开的资产目录
系统 SHALL 使用明确的公开资源目录存放要展示在网站上的图片和媒体。

#### Scenario: 文章包含图片
- **WHEN** 一篇公开文章引用图片
- **THEN** 图片从公开资源路径加载，而不是直接从原始 flomo 导出目录加载

### Requirement: 网站可发布到 GitHub Pages
项目 SHALL 提供适合 GitHub Pages 部署的静态构建产物。

#### Scenario: 发布流程运行
- **WHEN** 网站构建命令成功完成
- **THEN** 生成的静态产物可以部署到 GitHub Pages
