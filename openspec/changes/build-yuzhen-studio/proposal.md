## 背景与动机

Yuzhen 需要一个面向读者的个人网站，部署在 GitHub Pages 上，用来展示经过筛选的公开文章、个人作品和长期关注的主题，而不是直接公开原始日记或 flomo 导出内容。

这个网站会成为 **Yuzhen's Blog** 的长期入口：一个记录生活、工作和 AI 时代变化的公开创作空间。

## 变更内容

- 创建一个名为 **Yuzhen's Blog** 的静态个人网站。
- 首页展示网站定位、精选文章、长期主题、作品入口和最近更新。
- 增加面向读者的主要栏目：文章、主题、作品、关于。
- 支持一套“先筛选、再发布”的内容模型，方便后续逐步加入公众号文章、精选短札、个人作品和其他公开内容。
- 以 GitHub Pages 作为第一版发布目标。
- 原始 flomo 导出和私人日记内容默认不进入公开网站，除非某条内容被明确筛选、编辑并发布。
- 暂不做公众号/flomo 全自动同步、评论、搜索、订阅、私密归档浏览等复杂功能。

## 能力范围

### 新增能力

- `public-personal-site`：定义 Yuzhen's Blog 面向读者的网站结构，包括导航、首页、内容列表、详情页和公开品牌定位。
- `content-publication-workflow`：定义公开文章、主题、作品和精选短札如何组织、标注来源、构建并发布到 GitHub Pages。

### 修改能力

- 无。

## 影响范围

- 当前仓库会新增一个静态网站项目。
- 会增加 GitHub Pages 所需的构建和部署配置。
- 公开内容文件与公开媒体资源会和原始 flomo 导出分开管理。
- 未来如果要迁移公众号文章或 flomo 内容，会基于本次建立的公开内容模型继续扩展。
